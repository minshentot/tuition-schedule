6
建议家长 / 学生 每天至少查看一次 本系统，以获取最新课程与功课安排。

🧭 老师管理说明

本页面显示全部学生排课资料，网页内容由 Google Sheet 自动同步。老师可通过总表快速搜索学生、科目、日期与功课。

📱 手机上快速修改时间表
  1. 打开 Google Sheet，并以你的 Gmail 帐号登入。
  2. 直接修改日期、时间、学生、科目、功课或备注。
  3. Google Sheet 会自动保存，无需手动点击保存。
  4. 家长 / 学生刷新网页后，就会看到更新后的内容。
🔑 Access Code 管理说明
  • 所有 access code 资料仍储存在网页代码中的 ACCESS_CODES 对象。
  • shortName 必须与 Google Sheet 的 students 栏名字一致。
  • 若需新增学生，复制一个对象后修改姓名、shortName 与 code 即可。
  • 若是家庭共用 code，可使用 groupShortNames 让一个账号显示多位学生资料。
